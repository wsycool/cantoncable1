# cantoncable.com 网站操作指南

> 本指南帮助你把网站迁移到 **GitHub + Cloudflare Pages 自动部署** 模式。
> 完成一次性设置后，以后每次更新只需把文件推送到 GitHub，网站会在约 1 分钟内自动更新，无需再手动上传。

---

## 一、网站文件结构

```
cantoncable/                  （GitHub 仓库根目录 = 网站根目录）
├── index.html                首页（公司介绍、产品、联系方式）
├── certificates.html         ★ 认证证书展示页（更新证书只改这一个文件）

│   ├── certificates/         ★ 证书 PDF 放在这里
│   └── img/                  证书封面缩略图放在这里
├── README.md                 仓库说明
└── 操作指南.md               本指南
```

## 二、一次性设置：GitHub 仓库 + Cloudflare 自动部署

### 第 1 步：在 GitHub 创建仓库并上传代码

**方式 A：网页操作（推荐，无需安装任何软件）**

1. 登录 GitHub，点击右上角 **+** → **New repository**。
2. 仓库名填写 `cantoncable`（或其他你喜欢的名字），选择 **Public**（Cloudflare Pages 免费版私有仓库也支持，Public 更省事），点击 **Create repository**。
3. 在仓库页面点击 **Add file** → **Upload files**，把网站全部文件拖进去（保持上面的目录结构），点击 **Commit changes**。

**方式 B：命令行（熟悉 git 的话）**

```bash
cd cantoncable          # 进入网站文件夹
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/你的用户名/cantoncable.git
git push -u origin main
```

### 第 2 步：Cloudflare Pages 连接 GitHub 仓库

> ⚠️ **重要**：如果你现在的网站是用"直接上传"方式部署的，Cloudflare **不允许**给老项目补绑 Git。
> 所以需要**新建一个 Pages 项目**，部署成功后把域名转过去，网址不变，切换过程只有几分钟。

1. 登录 Cloudflare Dashboard → 左侧 **Workers & Pages** → **Create** → 选择 **Pages** → **Connect to Git**。
2. 授权 GitHub 账号，选择刚才创建的 `cantoncable` 仓库。
3. 构建设置（Build settings）：
   - Framework preset：**None**
   - Build command：**留空**
   - Build output directory：**`/`**（斜杠，表示根目录）
4. 点击 **Save and Deploy**，约 1 分钟后会生成一个临时地址 `xxx.pages.dev`，打开确认网站正常。
5. **转移域名**：
   - 进入**旧的** Pages 项目 → **Custom domains** → 把 `cantoncable.com` 移除（Remove）。
   - 进入**新的** Pages 项目 → **Custom domains** → **Set up a custom domain** → 输入 `cantoncable.com` → 确认。
   - 因为域名 DNS 本来就在 Cloudflare，解析会自动配置好，几分钟内生效。
6. 建议顺手把 `www.cantoncable.com` 也加到新项目的 Custom domains 里。
7. 确认新网站正常后，旧项目可以保留或删除（Pages 项目删除不影响域名）。

**设置完成！以后 push 到 GitHub 的 main 分支，Cloudflare 就会自动构建并上线。**

## 三、日常更新

### 1. 添加或更新一份认证证书（最常见的操作）

**第 1 步：上传 PDF**

- 把 PDF 文件名改成**英文小写、无空格**（如 `iso-9001-2025.pdf`、`type-test-35kv.pdf`）。
- 在 GitHub 仓库里进入 `assets/certificates/` 文件夹 → **Add file** → **Upload files** 上传。

**第 2 步：（可选）上传封面缩略图**

- 把 PDF 第一页截图或导出为 PNG/JPG（建议宽 600px 以上，3:4 竖版最佳），上传到 `assets/img/`。
- 没有缩略图也可以跳过，页面会自动显示默认封面。

**第 3 步：在证书列表里加一段**

1. 打开仓库里的 `certificates.html`，点右上角的**铅笔图标 ✏️** 在线编辑。
2. 找到文件下方注释 **"★ 更新证书只需修改这里 ★"** 处的 `const CERTS = [ ... ];`。
3. 复制其中一段花括号 `{ ... }`，粘贴到数组末尾（注意前一段末尾要有逗号），改成你的信息：

```js
        {
            title: "ISO 9001:2015 Quality Management System",   // 证书名称（卡片标题）
            issuer: "Issued by XXX, valid until 2028",          // 发证机构 / 有效期
            category: "Management System",                      // 分类（用于顶部筛选按钮）
            file: "assets/certificates/iso-9001-2025.pdf",      // PDF 路径（第1步的文件名）
            thumb: "assets/img/iso-9001-2025.png"               // 缩略图路径（没有就删掉这一行）
        },
```

4. 页面底部的 **Commit changes** 保存。约 1 分钟后刷新 `cantoncable.com/certificates.html` 即可看到。

> 💡 删除证书：把对应的那一段 `{ ... }` 删掉即可。
> 💡 更新证书（换新版 PDF）：直接用同名文件覆盖上传 `assets/certificates/` 里的旧 PDF 即可，代码不用动。

### 2. 修改首页文字 / 联系方式 / 产品信息

- 打开 `index.html` → 铅笔图标编辑 → 找到对应文字直接改 → Commit changes。
- 所有可见文字都在 HTML 里，对照页面位置找即可，注意不要改动 `< >` 标签符号本身。

### 3. 更省心的方式

任何时候都可以把新的 PDF 或想改的内容**直接发给 Kimi**，说明"更新到我的网站"，Kimi 会帮你改好代码并给出需要上传的文件。

## 四、常见问题

| 问题 | 解决办法 |
|---|---|
| push 后网站没更新 | 到 Cloudflare Pages 项目的 **Deployments** 看最新部署状态；部署成功但页面没变，按 `Ctrl+F5` 强制刷新（CDN 缓存） |
| PDF 点击后 404 | 检查 `file:` 路径里的文件名和实际上传的文件名**完全一致**（区分大小写） |
| 网页上传文件失败 | GitHub 网页上传单个文件不能超过 25MB；更大的文件请用 git 命令行（上限 100MB） |
| 部署失败 | Pages → Deployments → 点失败的那次看日志；纯静态站最常见原因是输出目录没填 `/` |
| 想让网站被 Google 更快收录 | 到 Google Search Console 提交 `https://cantoncable.com/sitemap.xml`（本仓库已自带此文件） |
